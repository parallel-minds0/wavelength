# wavelength Handbook

This handbook covers using wavelength in Blender and developing its implementation.
The same Markdown sources build the searchable HTML site and a single PDF book.
The generated reference reads the current source; annotated examples are extracted
directly from code rather than copied into the handbook.

Start with the User Guide for authoring a level. Use the Developer Guide for
ownership, data contracts, lifecycle, build tooling and regression checks.
Historical investigations are retained in the archive and are not descriptions
of the current implementation.
