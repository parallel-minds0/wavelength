# Sprites

2D SVG or PNG entity-reference artwork belongs here. These files are editor representations and are not exported as GoldSrc or Quake game assets.

The bundled `icons/` directory contains the existing Wavelength HL1 entity icon
pack, recovered from the older checkout's development assets. `manifest.json`
maps abstract HL1 entities and compatible Source 1 helper classes to 30 reusable
SVGs. Real engine model representations take precedence; icons are lightweight
editor helpers and also supply cached browser thumbnails. No SVG import extension
is required.
