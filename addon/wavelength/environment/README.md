# Wavelength environment

Versioned assets used while developing and testing Wavelength.

- `models/` — model references used by the in-editor entity representation system.
- `maps/` — small maps used for manual export/build/editor testing.
- `sprites/` — SVG/PNG artwork used as 2D entity references.

These are Wavelength development/reference assets, not a place to redistribute game assets without permission.
