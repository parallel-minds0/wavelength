# Wavelength Terrain

In the Wavelength workspace, hold the brush primitive button and choose
**Create Terrain Plane**. Click to start the footprint, move the mouse, and click
again to place it. Placement uses the same surface orientation and Blender snap
settings as the other brush tools. There is no height/extrusion phase.
**Add > Mesh > Terrain** (or F3: Terrain) also creates a flat footprint at the cursor.

Select the plane and click **Create Paintable Displacement** in the tool column
or **Object Properties > Wavelength Terrain**. This explicitly subdivides the
footprint into a general editable heightfield. New terrain starts with zero noise;
paint it or add procedural variation with Amplitude/Frequency/Seed. Source export
then samples the heightfield into engine displacement patches. A footprint that
has not been converted cannot silently export as a Source displacement.

Change Width, Length, Resolution, Elevation, Amplitude, Frequency or Seed.
Changes update the Geometry Nodes modifier live. Existing terrains remain
paintable without conversion. Dimensions use the owning
profile's authoring units; frequency is measured per authoring unit.

This is a general-purpose heightfield generated by the inspectable node group
`Wavelength · Heightfield Terrain · v3`. It is not built out of Source brushes.
Resolution controls the general mesh independently of any engine output grid.
The graph supports seeded noise plus a non-destructive painted control surface.
Heightmap inputs remain future work.

## Displacement from an existing brush face

Under the owning Source profile, select a Wavelength world brush. If it still has
live primitive generation, use **Finalize Geometry** first. Enter Edit Mode,
switch to Face Select, and select the planar convex four-sided faces to retain.
Choose **Face > Create Displacement from Face**, use the face context menu, or
search for the command with F3.

Wavelength creates an independent terrain surface for each selected face, using its corners,
orientation and material. Horizontal, sloped, vertical and tapered convex quads
are supported. Each starts flat, with zero noise amplitude. Select a new
surface to adjust Patch Power and use the normal terrain height/texture painting
tools. Each selected brush face owns one Source displacement patch.

The backing brush is removed automatically. Only selected faces become terrain,
so select every face you want to retain before converting. Undo restores the
complete brush and removes the generated surfaces. The new surfaces have no
parent/source-object dependency and can be moved, painted and sewn independently.
Their base quad, world placement, material and owning profile are preserved.

For old brush-linked surfaces, **F3 > Detach Displacements** makes them independent
and removes their backing brushes. Existing surfaces sharing a backing brush are
detached together. Legacy orphaned surfaces recover from their saved base-face
data when their original brush has already been deleted.

VMF export generates the required displacement backing from each surface's own
frame, including for legacy attachments. It does not reuse the old brush side's
outward plane orientation: that can transpose displacement data if the original
mesh has inward winding. Finalization bakes the surface while retaining its base
domain. Brush entities, non-quad faces and unfinalized generators are not accepted
as creation bases.

## Placement and painting

Enable **Flat Placement** in Terrain Properties or use the plane icon beside the
Terrain toolbar button. This shows the undeformed footprint for positioning.
Export and finalization always evaluate the full terrain, even while flat preview
is displayed. Painting switches back to the full surface.

Choose Raise / Lower, Smooth, or Texture Blend, then click **Paint Terrain**
(or its contextual toolbar button). Drag or hold LMB to paint. Ctrl lowers/erases;
Hold the paint button to open the paint-type menu; choose a type to start painting.
The button shows the chosen type's icon and a normal click reuses that type.
Shift smooths. The wheel adjusts brush radius. Esc/Enter/right click finishes
the painting session, then Ctrl+Z undoes it. Radius and height strength use the
owning profile's units. Painting is available before finalization.
Initial height strength scales with the footprint, so a flat Source surface gets
a visible deformation rather than a tiny fraction of an engine unit. Texture
painting enables Material Preview when starting from Solid/Wireframe shading so
layer blending can be seen.

Heights and layer weights live on a normalized 65x65 control surface generated by
nodes. The display mesh samples that surface, so changing procedural noise,
dimensions or display resolution preserves the painted layer. Fine paint detail
is limited by control resolution independently of the display mesh resolution.

Blender terrain can use a base material and **Paint Material** for two-layer
painting. The layer preview currently uses image base colors or diffuse-color
fallbacks, rather than reproducing arbitrary material node graphs.

Source terrain paints the alpha between the two layers of an assigned
**WorldVertexTransition** material (for example, installed concrete/blendconcdirt003a).
Alternatively, choose **Texture Blend**, select **Base Material** and **Second
Material**, then click **Create Blend Material**. Both must be Source materials
from the owning profile, with available base textures. Configure the project's
directory and game directory first. Wavelength generates and assigns a transition
VMT using the existing VTFs; it copies optional normal-map references and the base
material's surface property, rather than reproducing arbitrary shader features.

The generated VMT is saved under the project's `.wavelength/generated-assets`
folder and the selected game's `materials/wavelength/generated` folder. Export
restores these files from the recipe saved in the blend. Undo reverts the Blender
assignment but leaves reusable generated files. When distributing a map, include
the generated VMT and any custom texture dependencies; automatic BSP asset packing
is not provided. Source alpha weights are resampled and exported in VMF.

Assign materials through Blender's Material Properties or existing Wavelength
material tools. Material drops and Apply Material update the node input automatically.
The node group exposes a Material input too. Both UVMap and wavelength UV
layers are generated so Wavelength's game-material shaders display correctly.

## Sewn terrain and cave surfaces

Select two or more unfinalized paintable displacement surfaces in Object Mode.
Use **F3 > Sew Displacements**, the object context menu, or the terrain Properties
panel. Select the surface objects, rather than their parent brushes. The surfaces
must have the same owning profile and units, and matching complete base edges.
They can originate from different brush objects and face different directions, so a
floor, wall and ceiling can form one connected cave surface. Partial-edge joins
and more than two patches on one edge are currently rejected.

Sew averages shared boundary positions and keeps explicit neighbour links. Each
surface and its base-domain definition retain their identity. Shared boundaries use a
common sample lattice across display resolutions and Source powers; the finer
edge follows the coarser common curve. Noise and painting can still vary inside
each patch. **Smooth Seams** optionally relaxes boundary positions toward nearby
interior rows; normal sewing preserves the shape of sharp joins.

Start Paint Terrain on any member to paint across its connected surfaces, even
when the other members are not selected. The brush uses world-space distance and
the hovered surface normal; vector deformation lets a floor-to-wall join move
sideways as well as upward. The cursor follows whichever connected surface is
under the pointer. One paint-session undo restores all affected objects.
Texture painting requires matching materials/layers across the network; shared
alpha values stay aligned when the materials match.

**Unsew Displacements** removes the selected objects' neighbour links while
retaining their deformation. Move connected members together. Moving a base edge
away, deleting a neighbour, excluding a member from export or changing procedural
parameters in a way that tears a seam is diagnosed instead of silently exporting
a gap. Reselect the network and Sew again to reconcile changed surfaces.
Finalization preserves baked connections and export. To keep painting a network,
all of its members must remain procedural; unsew finalized members first.

Sewn generation uses a named vector field and an inspectable Geometry Nodes
modifier after brush-face mapping. Source output samples the evaluated surface
through its UV domain, preserving sideways deformation and each surface's own grid orientation.
Standalone Blender terrain uses the same sewing system without Source conversion.

## Source output

Create terrain under a Source profile to give it Source ownership. Set Patch
Power (2/3/4) and Patches X/Y. VMF export samples the evaluated heightfield into
5x5, 9x9 or 17x17 displacement patches. Shared global samples preserve seams;
the live viewport object stays a general terrain mesh. Assign a Source material
before export. Source transition-material alpha painting is supported.

The standalone heightfield converter uses the evaluated mesh, including changes
to the node graph. It requires a rectangular, unfolded heightfield: overhangs, vertical faces,
internal holes, unsupported boundaries and sheared transforms are rejected.
This is resampling, so low patch density can lose detail from the terrain mesh.
Use solid world brushes to enclose the map; displacement terrain is not a seal.

Owning profile identity and units are stored on creation. Switching the active
profile does not convert an existing object's ownership. A Blender-owned terrain
cannot silently become Source terrain; explicit profile conversion UI remains a
separate lifecycle feature.

## Finalization

Source renders the front of a displacement. New brush-face terrain uses the
brush's outward face direction even if its raw Blender mesh normals are reversed.
For an existing surface facing the wrong way, select it in Object Mode and use
**F3 → Flip Terrain Facing**, or the button in **Object Properties → Wavelength
Terrain**. This works on multiple selected terrains and preserves sculpting,
painted layers and sewn joins. Use Blender's Face Orientation overlay to inspect
fronts; cave walls and ceilings should face into the playable space.

Finalize Terrain bakes evaluated geometry into the object's mesh and disables
procedural regeneration. Source patch sampling settings freeze with the saved
definition. The baked heightfield can be edited with ordinary Blender tools;
Source export still validates/resamples it. Dyntopo/remeshing and arbitrary
sculpting may make it unsuitable for displacement conversion.
Sewn surfaces retain a quad UV sampling domain and vector displacement fields;
their Source adapter handles orientation and sideways deformation independently
of the ordinary heightfield converter's local-Z restriction.

## Validation

Blender integration tests cover node generation, UVs, seeded variation, live
updates, patch seams, powers 2/3/4, VMF output, finalization and hole rejection.
The generated sealed-room fixture has also compiled with Garry's Mod VBSP,
including displacement-neighbour and collision processing.
