# Wavelength editor layout

Wavelength extends Blender's editors. The workspace scopes editing behavior;
switching away leaves ordinary Blender interaction available. Existing layouts
are preserved. Use the Wavelength header menu to reset the workspace if desired.

| Task | Location |
| --- | --- |
| Profile management | Viewport header profile popover / Wavelength menu |
| Engine, map units, worldspawn and project/toolchain paths | Scene Properties → Wavelength Map |
| Build output, compilation, validation and reports | Scene Properties → Build & Validation |
| Validate, build, play and cancel | Compact viewport header buttons |
| Map grid spacing and snapping | Viewport grid popover; also linked from Overlays and Snapping |
| Primitive creation | Shift+A → Mesh; click-and-drag tools in viewport toolbar |
| Active drawing tool parameters | Blender active tool settings |
| Persistent primitive / assembly parameters | Object Properties → Assembly & Primitive Parameters |
| Export role and brush entity membership | Object Properties → Wavelength Object |
| Entity keyvalues, relationships and Source outputs | Object Properties → Entity Properties |
| Engine sun creation | Shift+A → Light → Wavelength Sun |
| Sun direction | Selected sun's viewport rings; Object Properties → Sun Direction & Preview |
| Selected object summary | Viewport Item sidebar → Map Object |
| Hollow, clip, conversion and assembly operations | Object context menu, filtered by selection and engine |
| Face texture alignment | Mesh Edit Mode → Item sidebar → Face Textures |
| Read/apply/copy/paste face mapping | Mesh Edit Mode context menu |
| Textures | Native external Asset Browser library, cached outside the map |
| Entities | Native Asset Browser Current File section |
| Object hierarchy and visibility | Native Outliner |
| Map import/export | File → Import / Export |
| Logs, asset reports and workspace feature toggles | Small Wavelength header menu |

All registered operators remain searchable through F3. Entity fields load when
the Object Properties inspector follows a new entity selection; apply commits
the edited fields. Hollow and clip actions ask for their parameters when invoked.
With a build output already configured, the header Build button runs directly;
otherwise it opens the output file selector. Build status appears in the status
bar, with detailed errors and selectable validation objects in Scene Properties.

The former giant sidebar, duplicate System Tree and HL1 Authoring panel are no
longer registered. Their reusable operators remain available. This rearrangement
does not introduce model indexing, new geometry algorithms or new engine formats.

Texture libraries are generated by a separate Blender process. Names, previews,
and source fingerprints persist under the user's Blender configuration directory
in `wavelength/asset-libraries`. The first generation can take time; completed
shards become browsable while it runs. Subsequent sessions reuse the saved files.
Only an applied/imported material enters the map. Reload checks source changes in
the worker. Generation uses one Blender thread and lower process priority on
Windows. No worker polling or repeated library refresh remains after completion.

Sun entities own an excluded Blender Sun child for actual viewport illumination.
The yellow ring changes heading; the blue ring changes elevation. The arrow shows
the direction light travels. Preview Scene Lighting enables Material Preview with
the scene's lights and world. Native light rotation/color/strength edits feed back
into engine metadata. Existing/imported light_environment entities receive the
same preview. The preview is approximate; engine ambient/HDR and baked-lighting
behavior still belong to the compiler.
